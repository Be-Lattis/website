Funktionen

Alles, was Sie zum Analysieren brauchen

Die meistgenutzten Funktionen von Excel, angetrieben von SQLite.

Unendliche Arbeitsfläche

Mehrere unabhängige Tabellen pro Blatt, jede mit einem feinen Rahmen. Beginnt eine in A1, übernimmt der Blattreiter ihren Namen.

Typisierte Spalten

Text, Ganzzahl, Dezimalzahl, Datum, Boolesch. Der Typ wird beim Tippen erkannt, blockiert nie die Eingabe und bleibt änderbar.

Local-first

Alles steckt in einer einzigen .lattis-Datei, leicht zu versenden oder zu archivieren, mit Wiederherstellung nach einem Absturz.

Vertraute Formeln

Eine Excel-ähnliche Sprache mit strukturierten Verweisen wie Kunden[Stadt]. SVERWEIS wird zu REFERENCE.

SQL-Reiter

Fragen Sie Ihre Tabellen mit SQL ab und ändern Sie sie, mit allen Objekten der Arbeitsmappe im Blick.

Lua-Skripte

Automatisieren Sie mit db.query() und Ereignissen. Eine Schutzfunktion stoppt Endlosschleifen, die Oberfläche friert nie ein.

Pivot-Tabellen

Sofortige Aggregationen dank des nativen GROUP BY der Engine, als Baum dargestellt.

Diagramme und Dokumente

Diagramme, die aus Ihren Daten gespeist werden, und Dokument-Reiter, um Ihre Analysen zu gestalten.

KI-Assistent, wenn Sie möchten

Ein Assistent-Reiter, standardmäßig deaktiviert, den Sie mit Ihrem eigenen Schlüssel oder Konto verbinden.

SQL

SQL und Raster, Seite an Seite

Ein GROUP BY im SQL-Reiter, und das Ergebnis erscheint als Raster, das Sie sortieren, filtern und weiterverwenden können.

Analyse

Analyse ohne Wartezeit

Pivot-Tabellen und Diagramme nutzen die native Aggregation von SQLite. Sie aktualisieren sich, sobald sich Ihre Daten ändern.

Lua

Mit Lua automatisieren

Eine einfache, sichere API, um Ihre Tabellen im Hintergrund zu bearbeiten, mit integrierter Referenz und Hinweisen beim Tippen.

for row in db.rows("SELECT _id, Prix FROM Produits") do
  db.update("Produits", row._id, { Prix = row.Prix * 1.03 })
end

Häufige Fragen

Ist Lattis wirklich kostenlos?

Ja. Alle Funktionen sind kostenlos, für private wie berufliche Nutzung, ohne Abo und ohne Pro-Version. Das Projekt finanziert sich über Unternehmensspenden, Partnerschaften, Schulungen und Begleitung.

Wo werden meine Daten gespeichert?

Auf Ihrem Rechner. Eine Arbeitsmappe ist eine .lattis-Datei mit einer SQLite-Datenbank. Nichts geht an einen Server, außer Sie verbinden selbst eine externe Datenbank.

Finde ich meine Excel-Gewohnheiten wieder?

Ja: Menüband, Kontextmenüs, Tastenkürzel, Rückgängig und Wiederholen, vertraute Formeln. SVERWEIS wird sogar automatisch in REFERENCE umgewandelt.

Auf welchen Systemen läuft Lattis?

Windows, macOS und Linux. Es ist eine native Anwendung in Go mit Wails und SvelteKit, ohne den Ballast von Electron.

Wann kann ich es ausprobieren?

Ab sofort: Eine erste Beta ist für Windows, macOS und Linux verfügbar. Die Schaltfläche Herunterladen holt automatisch die neueste Version für Ihr System.

Kann mein Unternehmen helfen?

Gern: mit einer Spende, einer Partnerschaft, einer Schulung für Ihre Teams oder individueller Begleitung. Schreiben Sie uns an contact@lattis.be.

Bereit für mehr Ordnung in Ihren Tabellen?

Probieren Sie die Beta aus und sagen Sie uns auf GitHub Ihre Meinung.
