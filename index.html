La souplesse d'un tableur.
La rigueur d'une base de données.

Lattis est un tableur de bureau, moderne et rapide, qui garde vos données en local dans SQLite et peut aussi se connecter à vos bases PostgreSQL, MySQL ou SQL Server.

Voir le projet sur GitHub Découvrir

Un tableur qui comprend vos données

Saisissez comme dans Excel. Lattis détecte vos tableaux et les transforme en vraies tables typées, sans que vous ayez à y penser.

Canevas infini

Plusieurs tableaux indépendants par feuille. Une ligne ou une colonne vide marque la fin d'un tableau, une fine bordure l'encadre.

Colonnes typées

Texte, entier, décimal, date, booléen. Le type est détecté pendant la saisie sans jamais la bloquer, et reste modifiable.

Local-first

Tout vit dans un fichier .lattis, une archive unique facile à envoyer ou à archiver, avec récupération après un plantage.

Habitudes d'Excel

Ruban, menus contextuels, raccourcis, annuler/rétablir partout : vous ne partez pas de zéro.

Tout ce qu'il faut pour analyser

Les fonctions les plus utilisées d'Excel, appuyées sur la puissance de SQLite.

Formules

Un langage proche d'Excel, avec références structurées comme Clients[Ville]. RECHERCHEV devient automatiquement REFERENCE.

Onglet SQL

Interrogez et modifiez vos tableaux en SQL, avec la liste des objets de votre classeur.

Scripts Lua

Automatisez avec db.query(), des évènements et un garde-fou contre les boucles infinies.

Tableaux croisés dynamiques

Agrégations instantanées, présentées en arborescence.

Graphiques et documents

Graphiques dynamiques alimentés par vos données, et onglets Document pour mettre en page vos analyses.

Assistant IA (optionnel)

Un onglet Assistant à activer si vous le souhaitez, avec votre propre clé ou compte.

SQL et grille, côte à côte

Vos tableaux sont de vraies tables : un GROUP BY dans l'onglet SQL et le résultat s'affiche comme une grille.

Analyse sans latence

Tableaux croisés dynamiques et graphiques s'appuient sur l'agrégation native du moteur.

Connecté à vos bases

Importez et rafraîchissez des données externes, à la manière de Power Query. Les mots de passe restent dans le trousseau de votre ordinateur.

Bases relationnelles

PostgreSQL, MySQL/MariaDB, SQL Server et SQLite.

API et fichiers

API REST JSON, fichiers Parquet et JSON.

Collaboration (en conception)

Un « Serveur Lattis » sur PostgreSQL pour travailler à plusieurs, avec des rôles et des droits. Cette fonction est à l'étude et n'est pas encore disponible.

Windows, macOS et Linux

Une application native construite en Go avec Wails et SvelteKit, sans la lourdeur d'Electron. Le projet est en développement actif : suivez son avancement et ses versions sur GitHub.
