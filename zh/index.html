功能

其他电子表格做不到的，Lattis 都能做

每个表格都是真正的 SQLite 表。您保留熟悉的网格，同时获得数据库带来的一切可能。

无限画布

每个工作表可容纳多个独立表格，各自带有细边框。若表格从 A1 开始，工作表标签将采用它的名称。

强类型列

文本、整数、小数、日期、布尔值。类型在输入时自动识别，从不阻碍输入，并可随时修改。

本地优先

一切都保存在一个 .lattis 文件中，便于发送或归档，并支持崩溃后恢复。

熟悉的公式

熟悉的公式语言，支持 客户[城市] 这样的结构化引用。VLOOKUP 会自动转换为 REFERENCE。

SQL 标签页

用 SQL 查询和修改表格，工作簿中的所有对象一目了然。

Lua 脚本

通过 db.query() 和事件实现自动化。内置保护机制会中断死循环，界面永不卡死。

数据透视表

即时聚合，以树形结构呈现。可通过公式添加计算列，例如日期的年份，用于分组或筛选。

图表与文档

由数据驱动的图表，以及用于排版分析结果的文档标签页。

AI 助手（可选）

助手标签页默认关闭，可接入您自己的密钥或账户。

SQL

SQL 与网格，并排呈现

在 SQL 标签页中执行 GROUP BY，结果即以网格显示，可排序、筛选并再次使用。

分析

零等待分析

数据透视表和图表基于 SQLite 的原生聚合，数据一变化就会立即更新。

常见问题

Lattis 真的免费吗？

是的。所有功能均免费，个人和商业用途皆可，没有订阅，也没有专业版。项目依靠企业捐赠、合作伙伴、培训和企业服务维持。

我的数据存放在哪里？

在您的电脑上。每个工作簿是一个包含 SQLite 数据库的 .lattis 文件。除非您主动连接外部数据库或自己的 Lattis 服务器，否则不会有任何数据发送到服务器。

我还能沿用以前的电子表格习惯吗？

可以：功能区、右键菜单、快捷键、撤销与重做、熟悉的公式。VLOOKUP 甚至会自动转换为 REFERENCE。

Lattis 支持哪些系统？

Windows、macOS 和 Linux。它是用 Go、Wails 和 SvelteKit 构建的原生应用，没有 Electron 的臃肿。

什么时候可以试用？

现在就可以：首个测试版已支持 Windows、macOS 和 Linux。下载按钮会自动为您的系统获取最新版本。

架构

技术架构

写给好奇的你：原生应用、每个文件里都有一个真正的数据库，团队协作时还有可自托管的服务器。

原生应用

使用 Go 编写，界面采用 SvelteKit，由 Wails 整合。适用于 Windows、macOS 和 Linux 的真正原生应用，轻快流畅，不依赖 Electron。

每个文件都是数据库

每个 .lattis 文件都自带一个 SQLite 数据库。无需额外安装，数据随文件一起走。

公式与脚本

计算由 SQL 引擎完成。Lua 脚本运行时绝不会让界面卡住。

助手与 MCP

内置 MCP 服务器，开启后可让 Claude 等助手处理当前打开的工作簿。

Lattis 服务器

团队协作时使用自托管服务器。需要 PostgreSQL 18；支持 Docker 或 Kubernetes 部署。也可以在浏览器中编辑。

离线与 NAS

断网时也能继续工作，联网后自动同步。没有服务器时，一个共享文件夹或 NAS 就足以多人协作。
