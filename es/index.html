Funciones

Todo lo que Excel no hace

Cada tabla es una tabla SQLite real. Conservas la cuadrícula y ganas todo lo que una base de datos hace posible.

Lienzo infinito

Varias tablas independientes por hoja, cada una enmarcada por un borde fino. Si una empieza en A1, la pestaña toma su nombre.

Columnas tipadas

Texto, entero, decimal, fecha, booleano. El tipo se detecta mientras escribes, nunca te bloquea y siempre se puede cambiar.

Local-first

Todo cabe en un único archivo .lattis, fácil de enviar o archivar, con recuperación tras un cierre inesperado.

Fórmulas conocidas

Un lenguaje parecido al de Excel, con referencias estructuradas como Clientes[Ciudad]. BUSCARV se convierte en REFERENCE.

Pestaña SQL

Consulta y modifica tus tablas en SQL, con todos los objetos del libro a la vista.

Scripts Lua

Automatiza con db.query() y eventos. Un mecanismo de seguridad detiene los bucles infinitos: la interfaz nunca se congela.

Tablas dinámicas

Agregaciones instantáneas gracias al GROUP BY nativo del motor, presentadas en árbol.

Gráficos y documentos

Gráficos alimentados por tus datos y pestañas Documento para maquetar tus análisis.

Asistente de IA, si lo quieres

Una pestaña Asistente desactivada por defecto, que puedes conectar a tu propia clave o cuenta.

SQL

SQL y cuadrícula, lado a lado

Un GROUP BY en la pestaña SQL y el resultado aparece como una cuadrícula que puedes ordenar, filtrar y reutilizar.

Análisis

Análisis sin esperas

Las tablas dinámicas y los gráficos se apoyan en la agregación nativa de SQLite. Se actualizan en cuanto cambian tus datos.

Automatizar con Lua

Una API sencilla y segura para trabajar con tus tablas en segundo plano, con referencia integrada y avisos mientras escribes.

for row in db.rows("SELECT _id, Prix FROM Produits") do
  db.update("Produits", row._id, { Prix = row.Prix * 1.03 })
end

Trabajo en equipo

El Servidor Lattis, autoalojado sobre PostgreSQL: edición entre varios en directo, roles y permisos, trabajo sin conexión, Data Lake y edición desde el navegador. Un libro también se puede compartir en una carpeta de red o un NAS.

Arquitectura

Bajo el capó

Para los curiosos: una aplicación nativa, una base de datos real dentro de cada archivo y un servidor autoalojado para trabajar en equipo.

Aplicación nativa

Go y SvelteKit unidos por Wails v3: un solo binario para Windows, macOS y Linux, sin Electron ni navegador incrustado aparte.

Una base en cada archivo

Un archivo .lattis es un archivo comprimido con una base SQLite en modo WAL: un solo escritor, lecturas en paralelo, guardado atómico y recuperación tras un cierre inesperado.

Fórmulas y scripts

Las fórmulas se traducen a SQL siempre que es posible. Los scripts Lua (gopher-lua) se ejecutan en un entorno aislado, con un tiempo límite y un botón Detener que los interrumpen sin congelar la interfaz.

Asistentes y MCP

Un servidor MCP local, protegido por un token, permite que un asistente como Claude lea y modifique el libro abierto, con el mismo ajuste de compartición de datos que el asistente integrado.

Servidor Lattis

lattisd (Go) delante de PostgreSQL 18, fuente de verdad: permisos aplicados por seguridad a nivel de fila (RLS), inicio de sesión OAuth con PKCE, administración web, edición en el navegador con lattis-engine en /app/. Despliegue con Docker Compose o un chart de Helm.

Sin conexión y NAS

Cada equipo guarda una copia SQLite local y una cola de envío que se reproduce al volver la red, con gestión de conflictos. Sin servidor, un libro en un NAS se comparte mediante registros de solo anexado, uno por equipo.

Preguntas frecuentes

¿Lattis es realmente gratis?

Sí. Todas las funciones son gratuitas, para uso personal y profesional, sin suscripción ni versión Pro. El proyecto se financia con donaciones de empresas, alianzas, formación y acompañamiento.

¿Dónde se guardan mis datos?

En tu ordenador. Un libro es un archivo .lattis que contiene una base SQLite. Nada se envía a un servidor, salvo que tú conectes una base externa o tu propio Servidor Lattis.

¿Conservo mis hábitos de Excel?

Sí: cinta de opciones, menús contextuales, atajos, deshacer y rehacer, fórmulas conocidas. BUSCARV incluso se convierte automáticamente en REFERENCE.

¿En qué sistemas funciona Lattis?

Windows, macOS y Linux. Es una aplicación nativa hecha en Go con Wails y SvelteKit, sin el peso de Electron.

¿Cuándo puedo probarlo?

Ya mismo: hay una primera beta disponible para Windows, macOS y Linux. El botón Descargar obtiene automáticamente la versión más reciente para tu sistema.

¿Puede ayudar mi empresa?

Con gusto: con una donación, una alianza, formación para tus equipos o un acompañamiento a medida. Escríbenos a contact@lattis.be.
