Features

Everything other spreadsheets don't do

Every table is a real SQLite table. You keep the grid, and you gain everything a database makes possible.

Infinite canvas

Several independent tables per sheet, each framed by a thin border. If one starts in A1, the sheet tab takes its name.

Typed columns

Text, integer, decimal, date, boolean. The type is detected as you type, never blocks your input, and can always be changed.

Local-first

Everything fits in a single .lattis file, easy to send or archive, with crash recovery built in.

Familiar formulas

A familiar formula language with structured references such as Customers[City]. VLOOKUP becomes REFERENCE.

SQL tab

Query and edit your tables in SQL, with every object in the workbook listed right beside you.

Lua scripts

Automate with db.query() and events. A safeguard stops infinite loops, so the interface never freezes.

Pivot tables

Instant aggregations, displayed as a tree. Add calculated columns with a formula, such as the year of a date, to group or filter.

Charts and documents

Charts fed by your data, and Document tabs to lay out your analyses.

AI assistant, if you want it

An Assistant tab that is off by default, which you can connect to your own key or account.

SQL

SQL and grid, side by side

Run a GROUP BY in the SQL tab and the result appears as a grid you can sort, filter and reuse.

Analysis

Analysis without lag

Pivot tables and charts rely on SQLite's native aggregation. They update as soon as your data changes.

Frequently asked questions

Is Lattis really free?

Yes. Every feature is free, for personal and professional use, with no subscription and no Pro edition. The project is funded by company donations, partnerships, training and business support.

Where is my data stored?

On your computer. A workbook is a .lattis file containing a SQLite database. Nothing goes to a server unless you connect an external database or your own Lattis Server yourself.

Will my spreadsheet habits still work?

Yes: ribbon, context menus, shortcuts, undo and redo, familiar formulas. VLOOKUP is even converted to REFERENCE automatically.

Which systems does Lattis run on?

Windows, macOS and Linux. It is a native application built in Go with Wails and SvelteKit, without the weight of Electron.

When can I try it?

Right now: a first beta is available for Windows, macOS and Linux. The Download button automatically fetches the latest version for your system.

Can my company help?

Gladly: through a donation, a partnership, training for your teams or tailored support. Write to us at contact@lattis.be.

Architecture

Under the hood

For the curious: a native application, a real database inside every file, and a self-hosted server when you work as a team.

Native application

Written in Go with a SvelteKit interface, brought together by Wails. A real application for Windows, macOS and Linux, light and fast, without Electron.

A database in every file

Every .lattis file holds its own SQLite database. Nothing else to install, and your data stays with the file.

Formulas and scripts

Calculations run on the SQL engine. Lua scripts run without ever freezing the interface.

Assistants and MCP

A built-in MCP server lets an assistant such as Claude work on the open workbook, if you turn it on.

Lattis Server

For teamwork, a server you host yourself. PostgreSQL 18 is required; Docker or Kubernetes are supported. Editing from the browser too.

Offline and NAS

Work carries on without a network and syncs when the connection returns. Without a server, a plain shared folder or NAS is enough to work together.
