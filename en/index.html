Features

Everything you need to analyze

Excel's most used features, powered by SQLite.

Infinite canvas

Several independent tables per sheet, each framed by a thin border. If one starts in A1, the sheet tab takes its name.

Typed columns

Text, integer, decimal, date, boolean. The type is detected as you type, never blocks your input, and can always be changed.

Local-first

Everything fits in a single .lattis file, easy to send or archive, with crash recovery built in.

Familiar formulas

An Excel-like language with structured references such as Customers[City]. VLOOKUP becomes REFERENCE.

SQL tab

Query and edit your tables in SQL, with every object in the workbook listed right beside you.

Lua scripts

Automate with db.query() and events. A safeguard stops infinite loops, so the interface never freezes.

Pivot tables

Instant aggregations thanks to the engine's native GROUP BY, displayed as a tree.

Charts and documents

Charts fed by your data, and Document tabs to lay out your analyses.

AI assistant, if you want it

An Assistant tab that is off by default, which you can connect to your own key or account.

SQL

SQL and grid, side by side

Run a GROUP BY in the SQL tab and the result appears as a grid you can sort, filter and reuse.

Analysis

Analysis without lag

Pivot tables and charts rely on SQLite's native aggregation. They update as soon as your data changes.

Frequently asked questions

Is Lattis really free?

Yes. Every feature is free, for personal and professional use, with no subscription and no Pro edition. The project is funded by company donations, partnerships, training and business support.

Where is my data stored?

On your computer. A workbook is a .lattis file containing a SQLite database. Nothing goes to a server unless you connect an external database yourself.

Will my Excel habits still work?

Yes: ribbon, context menus, shortcuts, undo and redo, familiar formulas. VLOOKUP is even converted to REFERENCE automatically.

Which systems does Lattis run on?

Windows, macOS and Linux. It is a native application built in Go with Wails and SvelteKit, without the weight of Electron.

When can I try it?

As soon as a release is published, the Download button fetches the latest one for your system. Every release is also on GitHub.

Can my company help?

Gladly: through a donation, a partnership, training for your teams or tailored support. Write to us at contact@lattis.be.
